# gdmarkdown

Pure-GDScript Godot 4.7 addon that renders Markdown into a `RichTextLabel`.
Read `docs/architecture.md` before changing the pipeline.

## Verification gate

Both must pass before any change is complete:

```sh
gdkit format check . && gdkit lint check . && gdkit uid check .
./addons/gdtest/gdtest run
```

`task` runs both. `gdkit format write .` fixes formatting; run it on a clean
tree.

## Constraints that bite

- Every GDScript warning is an error, including `inferred_declaration`, so
  `:=` does not compile here. Declare every type.
- `return_value_discarded` is an error. `PackedStringArray.append()` returns
  `bool` and `Signal.connect()` returns `int`. Accumulate into `Array[String]`
  and join with `MarkdownScanner.join()`.
- `tests/fixtures/kitchen_sink.bbcode` is a reviewed golden file. If a change
  moves it, read the diff and confirm the new output is correct before
  committing it.
- `addons/gdtest/` is installed by `gpm install` and is not committed. Never
  edit it, and never hand-edit `addons.lock`.
- `docs/images/*.png` are generated by `./scripts/capture-screenshots`, which
  needs a real rendering context: a headless run writes blank images. Rerun it
  after any change to rendering, and look at the result.
- The release manifest lives at `packaging/gpm-package.toml`, deliberately not
  at the repository root. Never bump a version by hand: the Release workflow
  takes a patch/minor/major choice, derives the version from the latest tag,
  and `scripts/set-version` injects it into `plugin.cfg` and the changelog.
  `scripts/package-addon --version X.Y.Z` injects it into the staged tree too,
  so a cut never depends on a committed file being current.
- Write changelog entries under `## [Unreleased]` as you go.
  `scripts/release-notes-present` fails a release when that section is empty,
  and the section becomes the GitHub release body.
- `main` is protected: pull requests required, `verify` must pass, no force
  pushes or deletions. Never push to `main` directly. The release workflow
  commits its bump to an ephemeral `release/vX.Y.Z` branch and opens an
  auto-merging pull request; see `docs/releasing.md`.
